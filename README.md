# Jarvis AI Voice Assistant

An AI-powered voice assistant built using Python with speech recognition and realistic male neural voice.

## Features

* 🎤 Speech Recognition
* 🗣️ Realistic Male Voice using Edge TTS
* 🌐 Open Google, YouTube, and GitHub
* 🔍 Voice-based Web Search
* ⏰ Time and Date Queries
* 👤 Personalized Responses
* 🚪 Exit Command

## Tech Stack

* Python
* SpeechRecognition
* Edge-TTS
* Pygame
* WebBrowser

## Installation

```bash
pip install -r requirements.txt
python jarvis.py
```
